# Smart Knowledge Assistant

A beginner-friendly full-stack AI project combining
Retrieval-Augmented Generation (RAG) and AI evaluation.

## Tech Stack

- React
- Vite
- Node.js
- Express
- Google Gemini API
- Git and GitHub

## Features

- Direct prompting vs. context-augmented prompting
- External knowledge retrieval
- Context-aware AI answers
- Hallucination reduction
- Automated test cases
- AI output evaluation
- Response consistency testing
- Token usage and latency measurement
- Before-and-after performance comparison

## Project Status

Initial repository setup completed.
Implementation will be added incrementally.

## Security

API keys must be stored in environment variables.
Never commit secrets to GitHub.
